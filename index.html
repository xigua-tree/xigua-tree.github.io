中国象棋机器人

▶ 演示

一台中国象棋机器人，摄像头识别局面、引擎决策、机械臂落子，全程自动对弈。

  • 硬件平台：DK-2500 + Intel Core Ultra 5 225U，全程 Python 开发
  • 机械结构：三自由度机械臂，闭环步进电机驱动，末端电磁铁吸子
  • 视觉识别：OpenCV 提取棋子坐标，自训练 YOLOv8n 模型分类棋子类别
  • 对弈引擎：棋盘局面转 FEN 串，接入 Pikafish 引擎返回 UCI 走法
  • 控制链路：二维视觉坐标 → 三维映射 → 运动学逆解 → 电机角度 → 机械臂落子
  • 交互与稳定：Qt 上位机；帧间校验 + 走法判断降低误判
PythonOpenCV机器人运动学Qt电路设计机械设计
