- 日期：2026-10-01

## 1. 项目概述

搭建一个**个人作品集网站**，用来展示自己的 DIY 电子项目和软件项目，兼具"求职简历"和"兴趣分享"两种用途。网站以**单页式**呈现，简洁、专业、有手作温度。

## 2. 目标与定位

- **内容类型**：电子/硬件类 + 编程/软件类作品（同一项目往往软硬兼有，不做硬件/软件二分）
- **用途**：求职展示 + 兴趣分享，两者兼顾
- **语言**：中文为主，技术名词保留英文（如 Arduino、FreeRTOS）
- **预算**：托管免费，域名后续再买（本期不买域名，先上线）

## 3. 网站结构（单页，从上到下）

```
导航栏：名字/Logo + 锚点（关于 · 作品 · 技能 · 联系）
├─ 首屏 Hero：名字 + 一句话定位 + 头像 + 关键链接
├─ 关于我：两三句自我介绍
├─ 作品集：项目卡片网格（核心板块）
├─ 技能：技术栈标签云
└─ 联系我：邮箱 · GitHub · B站
```

- **作品集不做硬件/软件分类**，所有项目统一排列。每张卡片用**技术标签**（如 `#Python` `#机械设计` `#Linux内核`）体现软硬兼修。
- 本期先做**卡片列表**（标题 + 简介 + 标签 + GitHub 链接），详情页/展开内容留到后续迭代。

## 4. 视觉风格

- **风格**：温暖纸张（米白底色 `#fdf8ef` + 暖橙强调色 `#c2703d`）
- 深色文字 `#3f3a33`，辅助灰 `#8a8177`，卡片白底 + 浅边框 `#e8ddc8`
- 整体气质：简洁、亲切、有手作温度，不像冷冰冰的模板

## 5. 技术方案

- **实现**：HTML + CSS 静态网站（单文件 `index.html` 起步，后续可拆分）
- **托管**：GitHub Pages（免费）
- **部署**：GitHub 仓库 `xigua-tree.github.io`（或任意仓库开启 Pages）
- **域名**：本期用免费地址，域名购买与绑定留待以后
- **头像**：使用用户提供的 `头像.png`
